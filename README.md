### PROJETO DE ADMINISTRAÇÃO DE MATERIAIS DE CONSTRUÇÃO

Este projeto foi uma ideia minha pensado em um ambiente recorrente onde é negligenciado a admnistração dos masteriais de construção.

### USO

A tela principal do programa é um gráfico da quantidade produzida determinado tempo mostrando uma visualização objetiva e clara.

### PRODUTOS

A tela de produtos é para a cadastração de produtos.

### MATERIA-PRIMA

A tela de matéria-prima é para a cadastração de matérias-primas.

### PRODUCAO

A tela de produção é para entrada de produções no dia.

### OBJETIVO

NÃO FOI TESTADO FORA DO AMBIENTE DE TESTES!

Este programa foi simplesmente feito para viés estudantis e não foi usado fora do ambiente de testes!
